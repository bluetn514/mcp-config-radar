# Security policy

MCP Parity is a local, read-only config comparison tool. It does not start configured servers, make network requests, or modify config files.

The report intentionally omits command arguments, environment values, URL credentials, and HTTP header values. Comparisons happen in memory. Do not attach unredacted config files to public issues.

To report a security concern, use GitHub's private vulnerability reporting for this repository rather than opening a public issue.
